# Traffic Sign Recognition System Using CNN and Transfer Learning Models

## Overview

This project implements Traffic Sign Recognition using Deep Learning techniques, including a custom CNN model and Transfer Learning models. The system classifies traffic signs from image datasets and compares model performance.

## Technologies Used

* Python
* TensorFlow / Keras
* OpenCV
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## Features

* Traffic Sign Classification
* CNN-Based Model
* Transfer Learning Models
* Model Training and Evaluation
* Performance Comparison

## Dataset

The project uses German and Indian Traffic Sign datasets for training and testing.

## Results

The models achieve high classification accuracy, with Transfer Learning models generally outperforming the custom CNN model.
