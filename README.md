# Traffic Sign Recognition System Using CNN and Transfer Learning Models

## Overview

This project presents a deep learning-based Traffic Sign Recognition System developed using Convolutional Neural Networks (CNN) and Transfer Learning techniques. The system is trained and evaluated on both the German Traffic Sign Recognition Benchmark (GTSRB) and Indian Traffic Sign datasets to accurately classify traffic signs under various real-world conditions.

The project explores the effectiveness of custom CNN architectures and pre-trained deep learning models for improving traffic sign recognition performance, a critical component of Intelligent Transportation Systems (ITS) and Autonomous Driving applications.

## Key Features

* Traffic Sign Classification using Deep Learning
* Custom CNN Model Implementation
* Transfer Learning-Based Classification
* Support for GTSRB and Indian Traffic Sign Datasets
* Model Training, Validation, and Testing
* Performance Evaluation and Comparison
* Data Preprocessing and Image Augmentation

## Technologies Used

* Python
* TensorFlow / Keras
* OpenCV
* NumPy
* Pandas

## Dataset

* German Traffic Sign Recognition Benchmark (GTSRB)
* Indian Traffic Sign Dataset

## Results

The models were evaluated using standard classification metrics such as Accuracy, Precision, Recall, and F1-Score. Transfer Learning models demonstrated superior performance by leveraging pre-trained feature extraction capabilities, while the custom CNN provided a strong baseline for comparison.

## Applications

* Autonomous Vehicles
* Advanced Driver Assistance Systems (ADAS)
* Intelligent Transportation Systems
* Traffic Monitoring and Road Safety
